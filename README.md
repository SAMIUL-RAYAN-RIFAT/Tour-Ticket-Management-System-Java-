# Tour-Ticket-Management-System-Java-
# Project Preview and Discussion
This is a very basic java project developed using Notepad++ and executed through CMD for academic evaluation purposes. 
This project was actually made  to demonstrate the fandamental properties of Java(like Abstract,Inheritance,Association,Interface, Encapsulation, Polymorphism etc). The main objective was to apply core Object-Oriented Programming (OOP) concepts in a practical system.
# Special Note
**Database implementation was not required for this project. Therefore, user account creation and login verification are handled using .txt files instead of a database management system.**
